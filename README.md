# FloodWise Dashboard

Build a fully functional, modern web application called FloodSense

for the HACKDAY 1.0 hackathon.

TAGLINE: Know the Risk. Stay Ahead.

PURPOSE:

FloodSense helps people understand flood risks and prepare

for potential flooding in their area.

TECH STACK:

React, TypeScript, Tailwind CSS, Lucide icons.

DESIGN:

Create a premium, professional dashboard with a dark navy,

blue and white color palette.

Make it responsive for desktop and mobile.

Use clean cards, modern typography, clear risk indicators,

and intuitive navigation.

FEATURES:

1. DASHBOARD

- Project name and navigation

- Location search and selection

- Flood risk level: Low, Moderate, High, or Severe

- Rainfall indicator

- Risk explanation

- Preparedness recommendations

2. LOCATION EXPLORER

Include sample Indian locations:

Delhi, Guwahati, Patna, Mumbai, and Chennai.

When a user selects a location, update the dashboard

with corresponding sample risk data.

Clearly label all sample data as simulated.

3. FLOOD RISK MAP

Create a visual map-style interface with location markers.

Use different colors to represent risk levels.

Allow users to select a location marker and view its

simulated risk information.

Do not claim simulated information is live data.

4. FLOODSENSE AI ASSISTANT

Create an interactive flood safety assistant.

Users can select questions such as:

- What should I do during a flood warning?

- What should I pack in an emergency kit?

- How can I prepare my family?

- What should I avoid during flooding?

Display useful, safety-focused answers.

Do not invent live emergency alerts.

5. EMERGENCY CHECKLIST

Create an interactive checklist with:

- Drinking water

- First aid kit

- Flashlight

- Important documents

- Emergency contacts

Allow users to mark items as completed.

Show checklist completion progress.

6. ALERT CENTER

Display sample flood alerts with location, risk level,

timestamp, and recommended action.

Clearly label them as DEMO ALERTS.

7. ABOUT FLOODSENSE

Explain the problem, solution, intended users,

and potential social impact.

FUNCTIONAL REQUIREMENTS:

- All navigation must work.

- Location selection updates risk information.

- Risk cards and markers are interactive.

- Checklist progress updates dynamically.

- Search and filters should work.

- Use reusable React components.

- Include realistic demo data.

- No dead buttons or broken interactions.

- Do not require paid APIs.

- Do not pretend simulated data is real-time data.

Build the complete working MVP.

Prioritize functionality, usability, and a polished

hackathon-ready experience over unnecessary animations.
